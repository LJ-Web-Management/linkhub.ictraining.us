Link Hub Admin

Sign in to edit links

Links are stored in the LJ-Web-Management/linkhub-data repository on GitHub, and changes show on the page about a minute after you publish. Sign in with a GitHub access token that can write to that repository.

How do I get a token?
  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Sign in as LJ-Web-Management. Set Repository access to Only select repositories → linkhub-data.
  3. Under Repository permissions, set Contents to Read and write.
  4. Generate it, copy it, and paste it above. Treat it like a password.
